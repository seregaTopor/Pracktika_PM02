# Автоматизированная система управления производством средств защиты растений

## Описание проекта

Информационная система для автоматизации процессов производства средств защиты растений, объединяющая в единую цифровую среду технологический отдел, производственный цех и лабораторию контроля качества.

**Разработчик:** Баталов Сергей  
**Учебная и производственная практика, 2025 г.**

---

## Возможности

- Ведение нормативно-справочной информации (продукты, сырьё, оборудование)
- Управление рецептурами и технологическими картами (версионность)
- Формирование производственных заказов и партий
- Контроль выполнения технологических операций в цехе
- Лабораторный контроль качества сырья и готовой продукции
- Регистрация отклонений и аудит событий
- Формирование аналитических отчётов

## Развёртывание

### 1. База данных
1. Установить Microsoft SQL Server
2. Выполнить скрипт `database/ProductionControl.sql`

### 2. API
1. Открыть `Contoso.ProductionAPIv2.sln`
2. Настроить строку подключения в `Web.config`
3. Запустить проект (F5)

### 3. Клиентские приложения
1. Открыть решение `ProductionControl.sln`
2. Настроить запуск нескольких проектов (API + WPF)
3. Запустить (F5)

## Бизнес-логика (триггеры БД)

- Запрет утверждения рецептуры при сумме долей ≠ 100%
- Только одна активная рецептура на продукт
- Только одна активная техкарта на продукт
- Запрет использования заблокированной партии сырья
- Автоматическая запись в историю изменений статусов
