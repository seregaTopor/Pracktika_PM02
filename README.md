# Система управления производством средств защиты растений

**Разработчик:** Баталов Сергей, 2026 г.

---

## О проекте

Информационная система для автоматизации производства средств защиты растений. Объединяет технологов, аппаратчиков и лабораторию в единую цифровую среду.

---

## Что умеет система

- Хранение и управление справочниками (продукты, сырьё, оборудование)
- Создание рецептур и технологических карт с контролем версий
- Формирование заказов и производственных партий
- Выполнение шагов в цехе с фиксацией параметров
- Лабораторный контроль качества
- Регистрация отклонений и аудит
- Формирование отчётов

---

## Из чего состоит

### База данных (MS SQL Server)
27 таблиц, 7 триггеров, тестовые данные

### API (ASP.NET Web API, .NET Framework 4.8)
10 контроллеров, авторизация с капчей

### Клиентские приложения (WPF)
- **Модуль технолога** — 8 разделов, полный функционал
- **Модуль лаборатории** — контроль качества
- **Модуль аппаратчика** — пульт линии, программа партии
- **Модуль администратора** — управление пользователями

---

## Как запустить

1. Выполнить скрипт `database/ProductionControl.sql` в MS SQL Server
2. Открыть API проект, настроить строку подключения в `Web.config`
3. Запустить решение — API + клиентские приложения
